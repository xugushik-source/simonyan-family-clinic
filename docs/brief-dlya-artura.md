# Что уточнить у Артура

Список того, что на сайте сейчас стоит как честная заглушка («уточняется») или демо-данные,
а не реальные подтверждённые факты о клинике. Собрано прямо по коду сайта (`src/config`,
`src/data`), а не по памяти — каждый пункт указывает, что именно сейчас показывается вместо
настоящих данных.

## Врачи и специализации — критично

- [ ] **Специализация Араксии Симонян.** Сейчас на сайте временно стоит в отделении
      «Терапия» с текстом «Специализация уточняется» — это временное распределение,
      не подтверждённый факт.
- [ ] **Специализация Алекса Симоняна.** Сейчас временно в отделении «Педиатрия» с тем же
      «уточняется» — тоже временное распределение, нужно подтвердить или переназначить.
- [ ] **Стаж, образование, сертификаты, курсы** — Артур, Араксия, Алекс. У всех троих стоит
      честная заглушка «Уточняется» вместо цифр и вузов — специально не стали придумывать
      конкретику под реальными именами.
- [ ] **Языки приёма** каждого врача. Список сейчас пустой у всех троих.
- [ ] **Фото врачей.** У всех 13 профилей врачей (включая семью) фото не загружено — стоит
      пустая карточка.

## Адрес и контакты — критично

- [ ] **Физический адрес клиники.** Сейчас «Адрес уточняется» на всех трёх языках — без него
      не работает и точка на карте.
- [ ] **Координаты для карты** (или просто адрес — можно найти по нему).
- [ ] **Работает ли кто-то по выходным.** Календарь записи сейчас открыт все 7 дней,
      08:00–20:00, для всех врачей — это допущение, а не подтверждённый график. Если по
      выходным работает не каждый врач (или никто) — нужно сузить.

## Прайс-лист — критично

- [ ] **Реальные цены** на приёмы и процедуры. Текущие цены — не цены клиники, а ориентир по
      рынку Тбилиси (подобраны по открытым источникам, чтобы цифры не выглядели случайными).
      Нужен настоящий прайс.
- [ ] **Валюта и способ оплаты** (лари, карта, только наличные?).
- [ ] **Работает ли клиника со страховыми компаниями.** Сейчас в FAQ стоит «Информация о
      работе со страховыми уточняется».
